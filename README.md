# המדדים שלי - Garmin Metrics Analyzer

אפליקציית ווב מקומית לניתוח אישי של נתוני בריאות משעון Garmin: שינה, HRV,
דופק, Body Battery ו-Stress - עם מנוע תובנות בוקר בעברית פשוטה.

## מה יש בפנים

- **תובנות בוקר** - השוואה של הלילה האחרון מול הבסיס האישי שלך (30 יום אחורה)
  והמלצה במילים פשוטות, למשל: *"ה-HRV נמוך ב-12% והדופק בשינה היה גבוה
  מהרגיל - מומלץ יום רגוע"*.
- **שינה** - ניקוד, משך, שלבים (Deep / Light / REM / Awake), שעת הרדמות ויקיצה.
- **HRV** - ערכים ליליים עם הטווח המאוזן האישי (של גרמין אם סונכרן, אחרת מחושב
  מההיסטוריה שלך), וזיהוי צניחות.
- **דופק** - דופק מנוחה, דופק ממוצע בשינה ודופק ממוצע בפעילות יומית (מחושב
  מפיצול דגימות הדופק לפי חלון השינה).
- **Body Battery + Stress** - טעינה בלילה מול ריקון ביום, ורמות סטרס.
- **מגמות** - סיכומים שבועיים/חודשיים עם אחוזי שינוי צבועים לפי כיוון המדד.
- **קורלציות** - זיהוי קשרים אישיים בנתונים (למשל שעת הרדמות ↔ HRV,
  סטרס ביום ↔ שינה בלילה שאחריו), כולל קשרים עם השהיה של יום.

## הפעלה - פקודה אחת

```bash
pip install -r requirements.txt   # פעם אחת בלבד
python app.py
```

זהו. הפקודה מתחברת לגרמין (בפעם הראשונה תתבקש להזין אימייל וסיסמה - ואם יש
MFA גם קוד), מושכת את הימים שחסרים, מחשבת הכל, ופותחת את הדשבורד בדפדפן
אוטומטית.

- `python app.py --days 90` - למשוך היסטוריה ארוכה יותר (מומלץ בפעם הראשונה,
  כדי שהבסיסים האישיים והקורלציות יהיו משמעותיים מיד)
- `python app.py --demo` - לראות את הדשבורד עם נתוני דמו, בלי חשבון גרמין
- `python app.py --no-sync` - רק לפתוח את הדשבורד בלי משיכה

## שימוש מהטלפון (כאפליקציה על מסך הבית)

האפליקציה בנויה כ-PWA — אפשר להוסיף אותה למסך הבית של הטלפון ולפתוח אותה
כמו אפליקציה רגילה (מסך מלא, אייקון משלה).

מכיוון שהנתונים נשמרים מקומית על המחשב שלך, הטלפון ניגש לשרת שרץ על המחשב.
לכן הדרך הפשוטה והפרטית: המחשב והטלפון על אותה רשת Wi-Fi ביתית.

```bash
python run.py --lan
```

הפקודה תדפיס את הכתובת המדויקת להקליד בטלפון, למשל `http://192.168.1.20:8765`.

- **iPhone (Safari):** פותחים את הכתובת → כפתור השיתוף → "הוסף למסך הבית".
- **Android (Chrome):** פותחים את הכתובת → תפריט (⋮) → "הוסף למסך הבית".

האייקון שנוצר יפתח את הדשבורד במסך מלא. עובד כשהמחשב דלוק ומחובר לאותה רשת.

> גישה מכל מקום (גם מחוץ לבית) דורשת חשיפת השרת לאינטרנט (טאנל או אחסון בענן),
> ואז הנתונים כבר לא נשארים רק על המחשב — זו החלטה נפרדת עם שיקולי פרטיות.

## דרכים נוספות להריץ (אופציונלי)

`python run.py` מרים רק את השרת בלי משיכה אוטומטית - ואז מתחברים ומסנכרנים
מלשונית **סנכרון** שבדשבורד עצמו. אפשר גם הכל מהטרמינל:

```bash
python -m garmin_analyzer.login          # התחברות חד-פעמית
python -m garmin_analyzer.sync --days 90 # משיכת היסטוריה
```

### הערות חשובות

- **Session Tokens נשמרים מקומית** בתיקיית `data/tokens` - הלוגין מתבצע פעם
  אחת בלבד, וכל הסנכרונים הבאים משתמשים בטוקנים. כך נמנעות חסימות 429 מגרמין.
- **הנתונים נשמרים ב-SQLite מקומי** (`data/health.db`) - ימים שכבר נמשכו לא
  נמשכים שוב, והתשובות הגולמיות של גרמין נשמרות בטבלת `raw_data` למקרה שנרצה
  לנתח מדדים נוספים בעתיד בלי למשוך מחדש.
- שום נתון לא יוצא מהמחשב שלך - אין שרת חיצוני.
- תיקיית `data/` כולה מוחרגת מ-git (`.gitignore`).

## מבנה הפרויקט

```
app.py                     # הכל בפקודה אחת: לוגין -> משיכה -> דשבורד
run.py                     # הפעלת השרת בלבד (כולל --lan לגישה מהטלפון)
garmin_analyzer/
  garmin_client.py         # לוגין + שמירת טוקנים (garminconnect/garth)
  sync.py                  # משיכת נתונים יומיים ופירסור
  db.py                    # סכמת SQLite
  baseline.py              # בסיסים אישיים (ממוצע/סטיה בחלון נע)
  insights.py              # מנוע תובנות הבוקר
  trends.py                # מגמות שבועיות/חודשיות
  correlations.py          # זיהוי קורלציות אישיות
  demo.py                  # נתוני דמו
  web/                     # FastAPI + דשבורד (HTML/JS ללא תלויות חיצוניות)
    static/                #   כולל manifest, service worker ואייקונים ל-PWA
tests/                     # 37 טסטים
```
