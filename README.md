# הכסף שלי - מעקב הוצאות עם תקציב סופ"ש

אפליקציית ווב לניהול כסף אישי, עם דגש על **דיווח הוצאות מהיר בסופ"ש**:
מגדירים תקציב (למשל ₪350), ובכל הוצאה נכנסים לשנייה — סכום → קטגוריה → נשמר.

## מה יש בפנים

- **דיווח בשתי נגיעות** - מקלדת סכום גדולה, נגיעה בקטגוריה שומרת מיד, כפתור ביטול
- **טבעת תקציב סופ"ש חיה** - כמה נשאר, עם צבע וסטטוס (בתקציב / נשאר מעט / חריגה)
- **סופ"ש מוגדר אישית** - ברירת מחדל חמישי 18:00 עד מוצ"ש, ניתן לשינוי בהגדרות
- **תובנות והשוואות** - ממוצע סופ"ש, יקר/חסכוני מהרגיל, לאן הולך הכסף, היסטוריה
- **מעקב חודשי מלא** - הכנסות והוצאות קבועות (משכורת, שכ"ד, מנויים), תנועות,
  מאזן, פירוט קטגוריות, וכמה מההוצאות הלכו בסופ"שים
- **גיבוי** - ייצוא/ייבוא JSON וייצוא CSV

## איך זה עובד

**אין שרת ואין חשבון.** האפליקציה היא קובץ HTML אחד שרץ כולו בדפדפן,
והנתונים נשמרים מקומית על המכשיר (localStorage). פרטי לחלוטין, עובד גם בלי
אינטרנט (PWA עם service worker).

## הפעלה

כל שרת סטטי מגיש את זה. הכי פשוט - **GitHub Pages**:

1. בעמוד ה-repo: Settings → Pages → Deploy from a branch → לבחור את הענף → Save
2. תוך דקה מקבלים כתובת `https://<user>.github.io/health-app/`
3. פותחים בטלפון → "הוסף למסך הבית" → משתמשים כמו אפליקציה

או מקומית: `python3 -m http.server` בתיקייה ולפתוח את הכתובת.

> הנתונים חיים בדפדפן של המכשיר. מומלץ לייצא גיבוי מדי פעם (הגדרות → ייצוא גיבוי).
